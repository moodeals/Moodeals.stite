MOODEALS SITE

To add a deal: open deals.json on GitHub, tap the pencil, copy one { ... } block,
add a comma after the block above it, paste, change the code/title/url, then Commit.
Netlify rebuilds in about a minute.

Rules for "code": letters and numbers only, no spaces (example: b0h86q).
Deal page:     yourdomain/CODE
Redirect link: yourdomain/go/CODE   <- use this one on HC
"price" and "image" can stay empty "".
